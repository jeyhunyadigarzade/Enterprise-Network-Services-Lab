Enterprise Network Infrastructure Lab (Cisco Packet Tracer)

Description:
Designed and implemented a multi-site enterprise network in Cisco Packet Tracer.
Performed IPv4 subnetting and IP addressing for multiple departments.
Configured VLANs (Finance, Sales, HR, Server Room) and implemented inter-network communication using OSPF dynamic routing.
Configured a centralized DHCP server with DHCP relay (ip helper-address) to automatically assign IP addresses across different networks.
Deployed DNS and Web Server services for internal network access.
Implemented switch port security using Shutdown and Restrict violation modes.
Verified end-to-end connectivity and network functionality through testing and troubleshooting.
